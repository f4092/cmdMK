# cmdMK

Terminal-based recreation of the classic *Mortal Kombat*, built with Python.

## REQUIREMENTS

- `Python 3`
- `macOS` or `Windows Terminal`
- `pynput` library
- Recommended terminal size: `140x40`

## INSTALLATION

**CLONE REPOSITORY:**

```bash
git clone https://github.com/f4092/cmdMK.git
cd cmdMK
```

**INSTALL PYNPUT:**

```bash
python3 -m pip install pynput
```

**RUN THE GAME:**

macOS:
```bash
python3 main.py
```

Windows:
```powershell
py cmdMK_windows_test.py
```

***On macOS, you may need to grant your terminal application 'Accessibility' permissions for keyboard input.***

## CONTROLS

| Key | Action |
|---|---|
| `A / D` | Move backward / forward |
| `W + A / D` | Directional jump |
| `S` | Crouch |
| `SPACE` | Block |
| `J` | Light punch |
| `I` | Heavy punch |
| `O` | Light kick |
| `P` | Heavy kick |
| `R` | Restart after a match |
| `Q` | Quit |
